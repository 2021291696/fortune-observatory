# 荣格象征词典（Jungian Symbol Dictionary）

一份关于梦与积极想象（Active Imagination）中常见象征的参考手册，配有荣格学派的解释框架。请记住：这些只是探索的起点，而非权威定论。梦者的个人联想永远优先。

---

## 如何使用本词典

```
象征解读流程
════════════════════════════════════════════════════════════════════════════════

    第一步：先看梦者的个人联想
    ┌─────────────────────────────────────────────────────────────────────────┐
    │  这个象征对"你"意味着什么？                                            │
    │  它唤起了哪些记忆、情绪或念头？                                        │
    │  这些个人联想是第一位的。                                              │
    └─────────────────────────────────────────────────────────────────────────┘

    第二步：梦中的情境
    ┌─────────────────────────────────────────────────────────────────────────┐
    │  这个象征在做什么？                                                    │
    │  梦者与它的关系如何？                                                  │
    │  伴随着什么情绪？                                                      │
    └─────────────────────────────────────────────────────────────────────────┘

    第三步：文化/原型层面的扩充放大（Amplification）
    ┌─────────────────────────────────────────────────────────────────────────┐
    │  只有在个人联想之后：才查阅集体层面的含义。                            │
    │  本词典提供的是原型层面的起点。                                        │
    │  用它来丰富梦者的体验，而不是取代。                                    │
    └─────────────────────────────────────────────────────────────────────────┘

    第四步：补偿性提问
    ┌─────────────────────────────────────────────────────────────────────────┐
    │  这个象征可能在如何平衡梦者的意识态度？                                │
    │  心灵（Psyche）想传达什么？                                           │
    └─────────────────────────────────────────────────────────────────────────┘
```

## 水的象征

```
水：无意识
════════════════════════════════════════════════════════════════════════════════
```

梦中的水几乎无一例外地代表无意识（Unconscious）的内容——即觉知表面之下的情感生活与本能生活。

| 象征 | 可能的含义 |
|------|-----------|
| 海洋（Ocean） | 集体无意识（Collective Unconscious）；心灵的浩瀚；一切生命的源头；可能令人被吞没（有"溺亡"风险）。参考文献：CW 9i, archetypes |
| 湖泊（Lake） | 个人无意识；有边界、可进入的深处；反思之地（如镜面）；"你的"深处栖息着什么？ |
| 河流（River） | 生命/时间之流；赫拉克利特：人不能两次踏入同一条河；心理能量（Libido）的流向；渡河 = 重大转折 |
| 水池/池塘（Pool/Pond） | 被容纳的无意识内容；有具体的东西待探索；平静 = 可以映照；浑浊 = 内容不明 |
| 雨（Rain） | 滋养性的无意识内容；来自上方/内在的恩泽；泪水、悲伤、洗涤；暴风雨 = 情绪动荡 |
| 洪水（Flood） | 无意识淹没自我（Ego）；旧结构的瓦解；被迫的转变；圣经意象：涤净 + 新的开始 |
| 溺水（Drowning） | 自我被淹没；退行到无意识状态；可能是转变性的（如受洗）；也可能是危险的（心灵解体） |
| 游泳（Swimming） | 穿行于无意识之中；自我保持觉知；自如 = 与无意识关系良好；挣扎 = 与情绪相处困难 |
| 潜水（Diving） | 有意的下潜；主动探索深处；在下方寻找某物；英雄的下界之旅（nekyia，冥府之行） |
| 清水（Clear Water） | 对无意识的清晰意识；材料已准备好被看见；透明、真实 |
| 深色/浑浊之水（Dark/Murky Water） | 未知的无意识内容；阴影（Shadow）材料；尚未准备好进入意识；可能有危险 |

水中生灵：

| 象征 | 可能的含义 |
|------|-----------|
| 鱼（Fish） | 正在浮动的无意识内容；某种东西正在"浮上来"；基督象征（Ichthys 鱼形符号）；自性（Self）从深处浮现 |
| 鲸（Whale） | 容纳之器（约拿）；被无意识吞没；转化的黑化阶段（Nigredo）；吞噬性的母亲 |
| 蛇/鳗（Serpent/Eel） | 本能的智慧；昆达里尼（Kundalini）能量；转变（蜕皮）；既可能是疗愈性的，也可能是威胁性的 |
| 鲨鱼（Shark） | 危险的无意识内容；掠食性情结（Complex）；某种在追逐你的东西；阴影的攻击性 |
| 章鱼（Octopus） | 多触手般的情结；母亲情结（吞噬性的）；某种以众多"触手"伸入生活的存在；感到被缠住 |

## 动物的象征

```
动物：本能与自然
════════════════════════════════════════════════════════════════════════════════
```

动物通常代表本能能量、身体，或我们身上与意识的整合程度不一的动物性面向。

家养动物：

| 象征 | 可能的含义 |
|------|-----------|
| 狗（Dog） | 忠诚、奉献、本能；"人类最好的朋友" = 已整合的自性；也可能是阴影（野狗 = 未驯服）；通往无意识的忠实向导。参考文献：CW 5（转化） |
| 猫（Cat） | 独立、神秘；阴性能本能；直觉、自足；埃及：神圣、月亮属性；女巫联想（阴影阴性） |
| 马（Horse） | 本性能量；力比多（Libido）、驱力；可以载你前行，也可能脱缰而去；飞马珀伽索斯：灵性超越。参考文献：CW 5（英雄之马） |
| 牛（Cow） | 滋养、母亲；神圣（印度教传统）；多产、丰饶；耐心、踏实 |

野生动物：

| 象征 | 可能的含义 |
|------|-----------|
| 狮（Lion） | 力量、王权；太阳象征；占主导地位的本能；可能是威胁也可能是盟友；炼金术："红狮" = 硫磺 |
| 熊（Bear） | 原初之力；吞噬性的母亲；冬眠 = 内省；复活（春天苏醒）；守护性的凶猛 |
| 狼（Wolf） | 阴影，内在的掠食者；群体归属感；本能 vs 文明；吞食（童话意象）；导师、引路者（原住民传统） |
| 蛇（Snake） | 转变（蜕皮）；昆达里尼、生命力；疗愈（阿斯克勒庇俄斯之杖）；诱惑（伊甸园）；大地/冥府的智慧。参考文献：CW 5、CW 9i 中大量论述 |
| 蜘蛛（Spider） | 编织命运；吞噬性的母亲；创造力（结网）；耐心、布设陷阱；阴影阴性 |
| 鹰（Eagle） | 精神、超越；目光高远（视角）；太阳的、阳性的；与神性的连接；折磨普罗米修斯者 |
| 猫头鹰（Owl） | 智慧（雅典娜的伴鸟）；夜视 = 在黑暗中看见；死亡预兆（某些文化中）；阴性的智慧；会"看"的无意识 |
| 渡鸦/乌鸦（Raven/Crow） | 死亡与转化；两个世界之间的信使；捣蛋鬼（Trickster）能量；炼金术黑化（Nigredo）；奥丁的伴侣（思想/记忆） |

神话生物：

| 象征 | 可能的含义 |
|------|-----------|
| 龙（Dragon） | 宝藏/自性的守护者；必须被英雄直面；原初混沌、未驯服的力比多；炼金术：原初物质（Prima Materia）。参考文献：CW 5（英雄神话） |
| 凤凰（Phoenix） | 死亡与重生；通过火的转化；从灰烬中升起；炼金术红化（Rubedo） |

## 建筑的象征

```
建筑：心灵的结构
════════════════════════════════════════════════════════════════════════════════
```

建筑通常代表心灵本身的结构。建筑的不同部分对应自性的不同面向。

| 象征 | 可能的含义 |
|------|-----------|
| 房屋（House） | 自性（Self）、整个心灵；"在我父的家里有许多住处"；自己的房子 = 自己的心灵；童年老宅 = 起源、早期自我。参考文献：CW 12（炼金术） |
| 地下室/地窖（Basement/Cellar） | 个人无意识；觉知"之下"的东西；被存放/被压抑的材料；未知的地下室 = 未知的自我 |
| 阁楼（Attic） | 更高的意识；旧日记忆、祖先传承；灵性渴望；日常生活"之上"的东西 |
| 房间（Rooms） | 人格的不同面向；未知的房间 = 未被发现的自性；房间众多 = 心灵复杂；上锁的房间 = 被防御的内容 |
| 门（Door） | 过渡、门槛；通往新内容的通道；上锁 = 设防；敞开 = 准备好探索 |
| 窗（Window） | 视角、观点；看进或看出心灵；意识注视世界；光进入（洞见） |
| 楼梯（Stairs） | 层级之间的移动；上行 = 趋向意识；下行 = 趋向无意识；螺旋 = 个体化（Individuation） |
| 神庙/教堂（Temple/Church） | 自性、神圣中心；圣地（Temenos）、受护空间；与超越者的连接；内在的神之形象 |
| 塔（Tower） | 孤立、囚禁；长发公主：被囚的阿尼玛（Anima）；灵性渴望；巴别塔：自大、僭越（inflation, hubris） |
| 城堡（Castle） | 被防御的自性；内在的宝藏（圣杯）；人格面具（Persona）的防御工事；必须被攻破或进入 |
| 废墟（Ruin） | 旧结构的崩塌；人格面具的消解；不再有用的东西；历史、祖先材料 |

## 人物形象

```
梦中的人：自性的各个面向
════════════════════════════════════════════════════════════════════════════════
```

记住主观层面（Subjective Level）：大多数人物代表梦者自身的某个部分。只有在主观解读穷尽之后，才去探索客观含义。

同性人物：

| 象征 | 可能的含义 |
|------|-----------|
| 阴影人物（Shadow Figure）（同性、黑暗、低劣） | 阴影（被拒绝的自性）；你不想成为的样子；跟随 = 情结在追逐；威胁 = 阴影想要被关注。参考文献：CW 9i 中大量论述 |
| 熟识的同性之人（Known Same-Sex Person） | 那个人的特质在你身上的体现；他/她对梦者代表着什么；投射的载体；问自己："X 是个怎样的人？" |
| 陌生的同性之人（Unknown Same-Sex Person） | 自性的未知面向；常常是阴影；未发展的潜能；原型人物（若带有神圣感/努秘 numinous） |

异性人物：

| 象征 | 可能的含义 |
|------|-----------|
| 阿尼玛/阿尼姆斯形象（Anima/Animus Figure）（陌生、令人着迷） | 心灵中异性面向的原型（Contrasexual Archetype）；"内在的他者"；灵魂形象；通往无意识的向导。参考文献：CW 7, CW 9i, CW 9ii |
| 梦中的恋人（Romantic Partner in Dream） | 关系动力；投射的载体；内在的阳 性/阴性；可能既是客观的也是主观的 |
| 前任伴侣（Ex-Partner） | 未解决的材料；那段关系所代表的东西；以那种形态出现的阿尼玛/阿尼姆斯（Animus）；怀念或警示 |

权威人物：

| 象征 | 可能的含义 |
|------|-----------|
| 父亲（Father） | 父亲情结的材料；内在父亲（苛责的或支持的）；权威、逻各斯（Logos）、结构；精神（智慧老人的雏形）。参考文献：CW 9i（父亲原型） |
| 母亲（Mother） | 母亲情结的材料；内在母亲（滋养的或吞噬的）；物质、自然、身体；大母亲（Great Mother）原型。参考文献：CW 9i（母亲原型） |
| 智慧老人/智慧老妪（Wise Old Man/Woman） | 玛纳人格（Mana Personality）；灵性权威；向导、导师；若与之认同可能导致自我膨胀。参考文献：CW 9i（玛纳人格） |
| 国王/王后（King/Queen） | 自性（统治中心）；占主导的意识；神圣权威；老王 = 需要更新。参考文献：CW 14（圣婚 coniunctio） |
| 孩子（Child） | 新的发展；永恒少年/少女（Puer/Puella）；神圣之子（自性正在浮现）；受伤的孩子（内在需要疗愈）。参考文献：CW 9i（儿童原型） |

集体人物：

| 象征 | 可能的含义 |
|------|-----------|
| 人群/暴众（Crowd/Mob） | 集体无意识；多个情结被激活；个体性的丧失；随大流的压力 |
| 陌生人（Stranger） | 自性的未知面向；阴影或新潜能；内在的"他者"；探索的邀请 |
| 追逐者/攻击者（Pursuer/Attacker） | 阴影情结；你一直在逃避的东西；转身面对 = 整合的开始；它要的是你的关注，而非毁灭 |

## 行动与事件

```
梦中行动：心灵正在做的事
════════════════════════════════════════════════════════════════════════════════
```

| 行动 | 可能的含义 |
|------|-----------|
| 坠落（Falling） | 自我控制感的丧失；放手（可以是正面的）；膨胀之后的泄气；"坠入"无意识；注意：落在哪里很重要 |
| 飞行（Flying） | 膨胀（Inflation）、高高在上；灵性渴望；逃离尘世牵挂；也可能说明"头抬得太高"、脱离现实；注意：你能否控制飞行？ |
| 被追赶（Being Chased） | 阴影在追逐；情结被激活；在逃避自性的一部分；转身面对 = 开始整合；你在回避什么？ |
| 赤身裸体（Being Naked） | 脆弱暴露；人格面具被剥除；羞耻，但也是真实；泄气（往往具有补偿性） |
| 考试（Taking a Test/Exam） | 自我评估；感觉没准备好；生活在"考验"你；表现焦虑；注意：你通过了吗？ |
| 牙齿脱落（Teeth Falling Out） | 力量/能力的丧失；衰老、必死性；沟通困难；咬/攻击性问题；对容貌的在意 |
| 死亡（Dying/Death） | 转化，而非字面意义的死亡；旧的存在方式的终结；自我之死（成人礼）；为新生命腾出空间。参考文献：CW 5（英雄的死与重生） |
| 杀戮/被杀（Killing/Being Killed） | 摧毁/被摧毁；自性的某个面向；通过"死亡"实现整合；注意：谁杀了谁，怎么杀的？ |
| 性行为（Sexual Activity） | 对立面的联合；圣婚（Coniunctio，炼金术联姻）；阳性/阴性的整合；有时也只是字面的性。参考文献：CW 14, CW 16 |
| 跨越门槛（Crossing a Threshold） | 过渡、成人礼；进入新阶段；阈限空间；无法回头 |
| 寻找/发现（Searching/Finding） | 对自性的追寻；失去的物品 = 失去的面向；找到 = 整合成为可能；注意：寻找/找到了什么？ |

```
物品：工具与象征

```

| 物品 | 可能的含义 |
|------|-----------|

| 钥匙（Key） | 通道、解答；能打开紧锁之门的物件；进入的权力；洞见、理解 |
| 剑（Sword） | 分辨、剖开；逻各斯、理智；攻击性（可正可负）；英雄的武器。参考文献：CW 5（英雄神话） |
| 杯/圣杯（Cup/Chalice） | 接纳、阴性；圣杯（自性）；容纳之器；共享、合一 |
| 戒指（Ring） | 完整、承诺；婚姻（内在的或外在的）；永恒、无始无终；自性象征（曼陀罗/Mandala） |
| 黄金/宝藏（Gold/Treasure） | 自性、最高价值；"阴影中的黄金"；炼金术的目标；被隐藏的珍贵之物。参考文献：CW 12（炼金术） |
| 石头（Stone） | 自性（哲人石）；恒久、根基；炼金术的哲人石（lapis）；也指冷漠、僵硬。参考文献：CW 12（炼金术） |
| 时钟/时间（Clock/Time） | 必死性、有限性；紧迫感、期限；"时间不多了"；人生阶段的考量 |
| 书（Book） | 知识、智慧；作为"生命之书"的无意识；已写就的内容（命运？）；阅读 = 认识自己 |
| 汽车/交通工具（Car/Vehicle） | 你如何穿行于人生；谁在开车？（自我还是情结？）控制、方向；身体（灵魂的载具） |
| 衣服（Clothing） | 人格面具、你呈现自己的方式；穿错衣服 = 人格面具失当；裸体 = 人格面具被剥除；新衣 = 新身份 |

## 自然现象

```
自然：力量与风景
════════════════════════════════════════════════════════════════════════════════
```

| 象征 | 可能的含义 |
|------|-----------|
| 太阳（Sun） | 意识、觉知；阳性原则；生命力、清明；也可能过于耀眼（膨胀）。参考文献：CW 5（英雄 = 太阳） |
| 月亮（Moon） | 无意识、映照；阴性原则；周期、变化；疯狂（lunacy，被月亮"占有"）。参考文献：CW 14（luna） |
| 星星（Stars） | 引导、命运；自性（遥远却在场）；灵性渴望；"摘星"之志 |
| 火（Fire） | 转化；激情、愤怒、能量；净化、毁灭；炼金术：煅烧（Calcination）。参考文献：CW 12（炼金术） |
| 山（Mountain） | 灵性渴望；障碍、挑战；启示之地（摩西、耶稣）；稳固、恒久；登山 = 个体化 |
| 森林（Forest） | 无意识；迷路（中年危机）；自然的、野性的自性；但丁：中年的"幽暗森林"；童话的发生地 |
| 花园（Garden） | 乐园、完整；被培育的自然（文明）；伊甸园（失落的纯真）；圣地（temenos）、神圣空间；自性的风景 |
