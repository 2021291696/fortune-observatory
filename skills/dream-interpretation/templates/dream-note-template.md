## C. 笔记：轻量反思

先读取目标目录的一篇同类笔记并沿用格式。默认 300—600 字。

```markdown

- 梦里发生了什么：
- 我明确记得的感受：
- 一个可能解释：
- 另一种解释：
- 与现实的证据：<已知 / 待观察>
- 梦里已有的资源：
- 接下来可以留意：
```

## 通用写入规则

- 只写入用户第二道选择实际选中的、已配置目标。
- 写入前检查同名文件；禁止覆盖，冲突时添加时间或序号。
- 多选时分别适配，不复制同一长文。
- 写入后报告绝对路径；跳过时说明原因。
